# Definition of Done (DoD)

## PRUEBAS
- [ ] DOD-01: Las pruebas unitarias cubren la lógica principal de la funcionalidad.
- [ ] DOD-02: Todas las pruebas unitarias se ejecutan sin errores.

## REVISIÓN DE CÓDIGO
- [ ] DOD-03: El código ha sido revisado por al menos otro integrante del equipo.
- [ ] DOD-04: El código ha sido aprobado mediante revisión por pares.
- [ ] DOD-05: El código cumple estándares de codificación y buenas prácticas.

## CERTIFICACIÓN
- [ ] DOD-06: El desarrollo sigue buenas prácticas de ingeniería de software y Scrum.
- [ ] DOD-07: La funcionalidad cumple criterios de calidad (rendimiento, usabilidad, confiabilidad).

## DOCUMENTACIÓN
- [ ] DOD-08: El código está documentado correctamente.
- [ ] DOD-09: El manual de usuario está actualizado.

## APROBACIONES TÉCNICAS
- [ ] DOD-10: La funcionalidad cumple la historia de usuario y criterios de aceptación.
- [ ] DOD-11: No presenta errores críticos ni vulnerabilidades.

## APROBACIONES ADMINISTRATIVAS
- [ ] DOD-12: El Product Owner valida la funcionalidad.
- [ ] DOD-13: El usuario final acepta la funcionalidad.

## DESPLIEGUE Y CIERRE
- [ ] DOD-14: La funcionalidad está desplegada en entorno de pruebas o producción.
- [ ] DOD-15: La historia está marcada como completada en el backlog con evidencias.
